# ES Tailor — 企業に合わせるES作成支援

会社情報と自分の経験を入力すると、その企業の価値観に接続した「受かるESの型」で
**自分自身のES下書き**を組み立てる支援ツールです。ビルド不要、`index.html` を
ブラウザで開くだけで動きます（オフライン可）。

## 使い方

1. `es-app/index.html` をブラウザで開く
2. ①企業情報（会社名・理念キーワード・魅力）②設問③自分の経験（STAR要素）を入力
3. 「ESを生成する」→ 右側に下書きと文字数、セルフ添削チェックが表示される
4. 文章は編集可能。コピー / .txt 保存ができる

## 設問タイプ

志望動機 / ガクチカ / 自己PR / 長所・短所 / キャリアプラン に対応。
設問文から自動でタイプを判定し、それぞれに適した構成（結論→STAR→企業接続→締め）で
文章を組み立てます。

## 設計方針（重要）

- **他者のES（ワンキャリア／マイナビ等の先輩ES）を転載・複製しません。** それらは
  著作物であり各サービスの規約で自動取得が禁止されているうえ、コピーは選考での
  盗用リスクになります。
- 本ツールは、公開されている企業理念等の情報と **あなた自身の経験** から、
  優れたESに共通する「型」で独自の文章を構成します。出力は必ず自分の言葉に
  推敲してから提出してください。
- 入力データはすべてブラウザ内で処理され、外部送信されません。
