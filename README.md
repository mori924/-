# AeroLab — 航空力学ラボ ✈️

飛行機を選んで、**翼まわりの空力解析**と**飛行特性**をインタラクティブに学べる教材アプリです。
React + Vite 製。実際の航空力学の理論（薄翼理論・パネル法・標準大気・Breguet 航続距離式・縦静安定理論）に基づいて計算しています。

## 使い方

```bash
npm install
npm run dev      # 開発サーバ起動
npm run build    # 本番ビルド (dist/)
npm run preview  # ビルド結果のプレビュー
```

ブラウザで開いたら、まず機体を選び、上部のタブで解析モジュールを切り替えます。

## 解析モジュール

1. **基本空力** — 揚力係数 C_L、抗力係数 C_D、揚抗比 L/D、ドラッグポーラー。
   有限翼の揚力傾斜 `a = a₀/(1+a₀/(πeAR))`、ドラッグポーラー `C_D = C_D0 + C_L²/(πeAR)`。
2. **翼型・圧力分布** — NACA 4桁翼型の形状生成と、**Hess–Smith パネル法**（定強度ソース＋渦パネル、Kutta 条件）
   による表面圧力係数 C_p 分布・揚力係数。迎角・翼型を変えてリアルタイム計算。
3. **飛行性能** — ISA 標準大気のもとでの失速速度、必要／利用可能推力・パワー、最大速度、上昇率、
   Breguet 航続距離、定常旋回（半径・旋回率・荷重倍数）。高度スライダーで密度高度の影響を観察。
4. **安定性・運動** — 縦の静安定（中立点・静安定余裕・C_m–C_L 曲線）、重心位置の可視化、
   運動方程式の数値積分による離陸滑走シミュレーション。

## 物理エンジンの構成 (`src/physics/`)

- `atmosphere.js` — 国際標準大気 (ISA) モデル（気温・気圧・密度・音速）
- `airfoil.js` — NACA 4桁翼型の座標生成（コサイン分布、キャンバー＋厚み分布）
- `panelMethod.js` — Hess–Smith パネル法（線形方程式を部分ピボット付きガウス消去で求解）
- `aero.js` — 有限翼の揚力・抗力・揚抗比
- `performance.js` — 飛行性能（失速・推力・上昇・航続・旋回）
- `stability.js` — 縦静安定と離陸滑走シミュレーション

パネル法は薄翼理論との比較で検証済み（NACA0012 の揚力傾斜 ≈ 0.121/deg、零揚力角や
よどみ点 C_p≈1・上面吸い込みピークが理論と一致）。

## 注意

- パラメータは公開資料に基づく**代表値**で、設計・認証データではありません。
- パネル法は**非粘性・非圧縮**の理論解です。失速（流れの剥離）や圧縮性（衝撃波・造波抗力）は
  モデル化していないため、高迎角・高マッハ数域では実機と乖離します。
